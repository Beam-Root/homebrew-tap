# beam-root/homebrew-tap

Homebrew formulae for [Beam Root](https://github.com/beam-root) products.

## Available formulae

- **beamca-agent** — short-lived machine certificate agent for the
  Beam CA private PKI service.

## Install

```sh
brew install beam-root/tap/beamca-agent
```

This taps the repo automatically. To tap explicitly:

```sh
brew tap beam-root/tap
brew install beamca-agent
```

## Releases

Binaries are published to
[beam-root/beamca-releases](https://github.com/beam-root/beamca-releases). Each
formula points at a specific signed + notarized release artifact for
darwin/{arm64,amd64} and linux/{arm64,amd64}.

## Updating formulae

Formulae here are generated by the source-side release script
(`scripts/release.sh` in the source repo). Don't hand-edit the
checksums in formula files; rerun the release script and copy the
updated file in.
